# EXP-3-M1 — 30-minute neural-network return forecaster

## Hypothesis

EXP-1 and EXP-2 repeatedly found small gross directional signal that did not survive the configured 0.10% commission per side plus 0.05% slippage per side. EXP-3 changes the trading problem rather than adding another classifier to the same 5-minute setup.

M1 asks whether a modest neural network on 30-minute market structure can rank sufficiently large 2-hour moves for the edge to survive the same friction model.

## Frozen chronology

- Model search/training: 2023–2024 only.
- Purged expanding validation: six two-month blocks during 2024.
- First forward model evaluation: 2025.
- 2025 may tune one execution axis only: minimum predicted 2-hour after-cost return.
- Frozen shadow test: 2026.
- After 2025 is printed, M1 architecture, features, targets and hyperparameters are frozen. Any model change becomes EXP-3-M2.
- 2026 has already been observed by older research and is therefore not globally pristine evidence.

## Data

Source files remain the existing Alpaca IEX 5-minute CSV.gz history under `data/5m/` for:

- AAPL
- MSFT
- GOOGL
- AMZN
- NVDA

Six complete regular-session 5-minute bars are aggregated into each 30-minute candle. Incomplete 30-minute buckets are discarded rather than filled.

## Targets

Signal information is available only after the current 30-minute candle is complete.

Entry is the next 30-minute candle open.

The main target is the realized after-cost return from that entry to the open four 30-minute intervals later, a 2-hour holding horizon. The same configured commission and slippage assumptions are embedded directly in the target.

The network also learns 1-hour and 4-hour after-cost returns as lower-weight auxiliary outputs when those same-session labels exist. The 2-hour head is the trading output.

All targets are same-session only. There is no overnight label.

## Model

A deliberately modest multilayer perceptron is searched within four layouts:

- 96 → 48 → 24
- 128 → 64
- 128 → 64 → 32
- 192 → 96 → 48

Each hidden block uses:

- Linear layer
- LayerNorm
- GELU or ReLU
- Dropout

Training uses AdamW, masked Smooth-L1 loss, gradient clipping, early stopping inside each chronological fold, and standardized features/targets fit only on the corresponding training partition.

The search may tune:

- hidden layout
- activation
- dropout
- learning rate
- weight decay
- batch size

Default search budget: 24 Optuna trials. Override locally with `EXP3_M1_TRIALS=<n>`.

## Model-selection rule

The neural network does not win merely by reducing regression loss.

Each trial is evaluated on purged chronological folds using the 2-hour prediction. The economic search objective rewards:

- positive average realized after-cost return in the highest-scored 10%
- positive average realized after-cost return in the highest-scored 5%
- positive rank relationship between predicted and realized net return
- a tolerable worst fold
- stability across folds

A trial is economically eligible only if mean top-10%, mean top-5%, median fold top-10%, and mean score-vs-return rank are all positive. If no trial satisfies this, the best diagnostic model is still frozen for research but the training gate is marked failed.

## Execution

Execution intentionally matches the label:

- long only
- enter at the next 30-minute open
- hold exactly 2 hours
- exit at the scheduled later open
- no overnight positions
- maximum 3 open positions
- maximum 20% of portfolio per position
- commission: 0.10% per side
- slippage: 0.05% per side

2025 tests only these five predeclared predicted-net-return thresholds:

- +0.00%
- +0.10%
- +0.20%
- +0.30%
- +0.40%

The selected threshold must also survive neighboring thresholds and the deployment-support gate. The gate only means paper-research eligibility, never real-money safety.
