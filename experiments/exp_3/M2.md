# EXP-3-M2 — Large 30-minute residual neural network

## Purpose

M1 showed that the 30-minute dataset was usable but the small neural network collapsed toward the unconditional negative after-cost mean and the final refit was undertrained. M2 keeps the data definition fixed while replacing the model/training core.

## Frozen chronology

- Model development/search: 2023-2024 only.
- Six expanding, purged 2024 validation blocks.
- First forward model evaluation: 2025.
- 2025 may select only the execution percentile.
- Frozen historical shadow test: 2026.
- Once 2025 is generated, `FROZEN_AFTER_2025.txt` prevents retraining M2 under the same name.

## Data and target

M2 reuses `data/experiments/exp-3-m1/dataset.parquet`.

- 30-minute regular-session bars built from six complete 5-minute bars.
- 65 model inputs: 60 engineered numeric features + 5 symbol indicators.
- Main target: 2-hour after-cost return from next 30-minute open to four bars later.
- Auxiliary targets: 1-hour and 4-hour after-cost return.
- Same friction model: 0.10% commission/side + 0.05% slippage/side.

## Network

M2 uses a large residual tabular MLP:

- input projection to width 384, 512 or 640;
- 2-4 residual MLP blocks;
- each residual block expands internally by 2x;
- LayerNorm + GELU + dropout;
- three return outputs (1h, 2h, 4h).

Depending on width/block count, the network is roughly in the low-single-digit millions of parameters, versus only 12,579 parameters for M1.

## Training

- 18 Optuna trials by default.
- 30 minimum epochs per fold.
- Up to 180 epochs per fold.
- 30-epoch economic early-stopping patience.
- AdamW + cosine learning-rate decay.
- Smooth-L1 return regression plus pairwise 2-hour ranking loss.
- Checkpoints are chosen by economic validation behavior: top-tail after-cost return and score-vs-return ordering, not regression loss alone.
- Final full 2023-2024 refit trains for at least 50 epochs and at most 150 epochs.

## Model-search gate

A model is economically eligible only if the purged CV results show:

- positive mean top-10% after-cost return;
- positive mean top-5% after-cost return;
- positive median top-10% return;
- positive mean score-vs-return rank correlation;
- at least four of six validation folds have positive top-10% returns.

If no trial passes, the best trial is retained only as a diagnostic and the training gate remains failed.

## Execution tuning

M2 uses one execution axis only: causal rolling percentile of the frozen 2-hour prediction score.

Candidate percentiles:

- p90 (top 10%)
- p92.5 (top 7.5%)
- p95 (top 5%)
- p97.5 (top 2.5%)
- p99 (top 1%)

The percentile at a timestamp is calculated only from prediction scores observed before that timestamp. Scores from all symbols at the current timestamp are added to history only after selection.
